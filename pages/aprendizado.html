Nível 1: Fundamentos de Redes

Comece aqui se você nunca estudou redes antes

O que é uma rede de computadores? +

Definição simples: Uma rede de computadores é um conjunto de dispositivos (computadores, celulares, servidores) conectados entre si para compartilhar informações e recursos.

Analogia: Pense em uma rede como uma estrada que conecta várias cidades. Os carros (dados) viajam por essa estrada para ir de uma cidade (computador) para outra.

Exemplos práticos:

  • Wi-Fi da sua casa conectando celular, notebook e smart TV
  • Rede de uma empresa conectando computadores dos funcionários
  • A própria Internet (rede mundial)
O que é um endereço IP? +

Definição: IP (Internet Protocol) é o endereço único que identifica cada dispositivo em uma rede, como se fosse o endereço de uma casa.

Formato: Um IP IPv4 tem 4 números separados por pontos, cada um variando de 0 a 255.

Exemplo: 192.168.1.10

Por que preciso disso? Sem endereço IP, os computadores não saberiam para onde enviar os dados. É como tentar enviar uma carta sem endereço!

Por que os computadores precisam de endereços? +

Identificação única: Cada dispositivo precisa de um "nome" único para que os dados cheguem ao destino correto.

Analogia do correio:

  • Remetente = seu computador (IP de origem)
  • Destinatário = servidor/computador destino (IP de destino)
  • Carta = pacote de dados
  • Endereço = IP address

Se dois computadores tivessem o mesmo IP, seria como duas casas com o mesmo endereço - o carteiro não saberia onde entregar!

O que significa IPv4? +

IPv4 = Internet Protocol versão 4

Características:

  • Criado em 1981 (ainda usado hoje!)
  • Usa 32 bits (4 grupos de 8 bits)
  • Permite aproximadamente 4,3 bilhões de endereços únicos
  • Formato: XXX.XXX.XXX.XXX (onde XXX vai de 0 a 255)

Exemplos válidos:
192.168.0.1
10.0.0.5
172.16.50.100

Curiosidade: Existe o IPv6 (versão 6) que foi criado porque os endereços IPv4 estão acabando!

Quais são as classes de endereços IP? +

IPs são divididos em classes (A, B, C) para organização:

Classe A: 1.0.0.0 até 126.255.255.255

  • Para redes MUITO grandes (milhões de dispositivos)
  • Exemplo: grandes provedores de internet

Classe B: 128.0.0.0 até 191.255.255.255

  • Para redes médias (milhares de dispositivos)
  • Exemplo: universidades, empresas grandes

Classe C: 192.0.0.0 até 223.255.255.255

  • Para redes pequenas (até 254 dispositivos)
  • Exemplo: sua casa, escritórios pequenos
  • 192.168.X.X é o mais comum em redes domésticas!

Nível 2: Sub-redes e Divisão

Entenda como dividir redes em partes menores

O que é uma sub-rede? +

Definição: Uma sub-rede é uma divisão lógica de uma rede IP maior em redes menores.

Analogia do prédio:

  • Rede completa = Prédio inteiro
  • Sub-redes = Apartamentos dentro do prédio
  • Cada apartamento tem seus próprios moradores (dispositivos)
  • Mas todos compartilham o mesmo endereço do prédio (rede principal)

Exemplo prático:

Rede original: 192.168.1.0 (pode ter 254 dispositivos)

Dividida em 4 sub-redes:

Sub-rede 1: 192.168.1.0 - 192.168.1.63 (62 hosts)
Sub-rede 2: 192.168.1.64 - 192.168.1.127 (62 hosts)
Sub-rede 3: 192.168.1.128 - 192.168.1.191 (62 hosts)
Sub-rede 4: 192.168.1.192 - 192.168.1.255 (62 hosts)

Por que dividir uma rede em sub-redes? +

Vantagens principais:

1. Organização

  • Separar departamentos (RH, TI, Vendas)
  • Isolar tipos de dispositivos (servidores, impressoras, usuários)

2. Segurança

  • Controlar quem se comunica com quem
  • Se uma sub-rede for atacada, as outras ficam protegidas

3. Performance

  • Menos tráfego desnecessário (broadcast limitado)
  • Rede mais rápida e eficiente

4. Aproveitamento de IPs

  • Evita desperdício de endereços
  • Cada setor tem só os IPs que precisa
O que é máscara de sub-rede? +

Definição: A máscara de sub-rede define qual parte do IP identifica a rede e qual parte identifica o host (dispositivo).

Formato: Também tem 4 números como o IP

Exemplo: 255.255.255.0

Como funciona:

IP: 192.168.1.10
Máscara: 255.255.255.0

  • 255.255.255 = parte da REDE (fixa pra todos)
  • .0 = parte do HOST (varia por dispositivo)

Então 192.168.1.10 e 192.168.1.20 estão na mesma rede!

Máscaras comuns:

255.255.255.0 = 254 hosts
255.255.255.128 = 126 hosts
255.255.255.192 = 62 hosts

O que significa aquela barra com número (/24, /26)? +

CIDR = Classless Inter-Domain Routing

É uma forma mais simples de escrever a máscara!

Ao invés de escrever 255.255.255.0, você escreve /24

O que significa o número?

Indica quantos bits são usados para identificar a rede.

/24 = 255.255.255.0 = 254 hosts
/25 = 255.255.255.128 = 126 hosts
/26 = 255.255.255.192 = 62 hosts
/27 = 255.255.255.224 = 30 hosts
/28 = 255.255.255.240 = 14 hosts

Regra prática: Quanto MAIOR o número após a barra, MENOR a rede (menos hosts).

O que é endereço de broadcast? +

Definição: O broadcast é o último endereço IP de uma sub-rede, usado para enviar dados para TODOS os dispositivos da rede ao mesmo tempo.

Analogia: É como um alto-falante que transmite um aviso para todos em uma sala de uma vez.

Exemplo:

Sub-rede: 192.168.1.0/26

  • Primeiro IP: 192.168.1.0 (endereço da rede - reservado)
  • IPs utilizáveis: 192.168.1.1 até 192.168.1.62
  • Broadcast: 192.168.1.63 (último - reservado)

Por que existe? Útil para:

  • Descobrir dispositivos na rede (ARP)
  • Serviços de rede (DHCP)
  • Avisos gerais

Nível 3: Conceitos Técnicos

Aprofunde-se nos cálculos e conversões

Como bits e binários funcionam em redes? +

O que são bits? Bits são a menor unidade de informação (0 ou 1). Computadores só entendem binário!

Por que isso importa em redes?

Cada número do IP (0-255) é representado por 8 bits em binário.

Decimal: 192
Binário: 11000000

Decimal: 168
Binário: 10101000

Tabela de conversão (valores de cada posição):

Posição: 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1
Binário: 1 | 1 | 0 | 0 | 0 | 0 | 0 | 0 = 192

Como usar: Some os valores onde tem "1"
128 + 64 = 192 ✓

Por que aprender isso? Para calcular sub-redes manualmente e entender máscaras!

Como calcular sub-redes manualmente? +

Exemplo prático: 192.168.1.0/26

Passo 1: Descobrir quantos bits são para hosts

32 bits totais - 26 bits de rede = 6 bits para hosts

Passo 2: Calcular tamanho da sub-rede

26 = 64 endereços por sub-rede

Passo 3: Calcular hosts utilizáveis

64 - 2 (rede + broadcast) = 62 hosts

Passo 4: Listar as sub-redes

Sub-rede 1: 192.168.1.0 - 192.168.1.63
Sub-rede 2: 192.168.1.64 - 192.168.1.127
Sub-rede 3: 192.168.1.128 - 192.168.1.191
Sub-rede 4: 192.168.1.192 - 192.168.1.255

Atalho: Cada sub-rede "pula" de 64 em 64!

Como converter CIDR em máscara decimal? +

Método passo a passo:

Exemplo: /26

Passo 1: Distribuir 26 bits de "1" nos 4 octetos

Octeto 1: 11111111 (8 bits)
Octeto 2: 11111111 (8 bits)
Octeto 3: 11111111 (8 bits)
Octeto 4: 11000000 (2 bits + 6 zeros)

Passo 2: Converter cada octeto para decimal

11111111 = 255
11111111 = 255
11111111 = 255
11000000 = 192 (128+64)

Resultado: /26 = 255.255.255.192

Tabela rápida de conversão:

/24 = 255.255.255.0
/25 = 255.255.255.128
/26 = 255.255.255.192
/27 = 255.255.255.224
/28 = 255.255.255.240
/29 = 255.255.255.248
/30 = 255.255.255.252

O que é gateway padrão? +

Definição: Gateway é o "portão de saída" da sua rede - normalmente o endereço IP do roteador.

Analogia: Se sua rede é um prédio, o gateway é a porta da frente. Tudo que sai ou entra passa por ali.

Por que existe?

  • Conecta sua rede local à Internet
  • Roteia dados entre diferentes redes
  • Gerencia tráfego de entrada/saída

Exemplo prático:

Rede: 192.168.1.0/24

  • Gateway (roteador): 192.168.1.1
  • Computadores: 192.168.1.2, 192.168.1.3, etc.

Convenção: Geralmente usa-se o primeiro IP utilizável como gateway, mas pode ser qualquer um!

O que é DHCP e como funciona? +

DHCP = Dynamic Host Configuration Protocol

O que faz? Distribui IPs automaticamente para dispositivos que se conectam à rede.

Sem DHCP: Você teria que configurar IP manualmente em CADA dispositivo (chato!)

Com DHCP: Conectou no Wi-Fi? Pronto, já ganhou um IP automaticamente!

Como funciona (simplificado):

  1. Dispositivo se conecta: "Oi! Preciso de um IP!"
  2. Servidor DHCP: "Aqui está: 192.168.1.50"
  3. Dispositivo: "Obrigado!" (usa esse IP)
  4. Quando desconecta, o IP volta pro "pool" de disponíveis

Informações distribuídas pelo DHCP:

  • Endereço IP
  • Máscara de sub-rede
  • Gateway padrão
  • Servidores DNS

Nível 4: Aplicação Prática

Resolva problemas reais do dia a dia

Quando usar /24, /26 ou /27? +

Escolha baseada no número de dispositivos:

/24 (255.255.255.0) = 254 hosts

  • Use para: Redes grandes (empresa média, escola)
  • Exemplo: 200 computadores + impressoras + servidores

/26 (255.255.255.192) = 62 hosts

  • Use para: Departamentos, pequenas empresas
  • Exemplo: 50 dispositivos em um setor

/27 (255.255.255.224) = 30 hosts

  • Use para: Equipes pequenas, salas específicas
  • Exemplo: 25 computadores em uma sala

/30 (255.255.255.252) = 2 hosts

  • Use para: Conexões ponto-a-ponto entre roteadores
  • Exemplo: Ligar dois roteadores (não desperdicia IPs)

Dica: Sempre deixe espaço pra crescimento! Se precisa de 50 hosts hoje, use /26 (62 hosts), não /27 (30 hosts).

Como escolher a máscara certa para minha rede? +

Passo a passo para decidir:

1. Conte os dispositivos

  • Computadores
  • Celulares/tablets
  • Impressoras
  • Servidores
  • IoT (câmeras, sensores)

2. Adicione margem de crescimento (30-50%)

Exemplo: 40 dispositivos hoje → planeje para 60

3. Escolha o CIDR que comporta

Preciso de 60 hosts → /26 (62 hosts) ✓
Preciso de 100 hosts → /25 (126 hosts) ✓
Preciso de 20 hosts → /27 (30 hosts) ✓

4. Considere segmentação

Melhor: 4 sub-redes /27 (30 hosts cada)
Do que: 1 rede /24 (254 hosts) bagunçada

Regra de ouro: Nem muito grande (desperdício) nem muito pequeno (sem espaço pra crescer)!

Qual a diferença entre IP público e privado? +

IP Público:

  • Único em toda a Internet (não pode repetir)
  • Fornecido pelo provedor de Internet
  • Acessível de qualquer lugar do mundo
  • Usado por servidores web, sites
  • Exemplo: 200.150.10.50

IP Privado:

  • Usado apenas DENTRO da sua rede local
  • Pode repetir em outras redes (não tem problema!)
  • NÃO funciona diretamente na Internet
  • Usado em casas, empresas, escolas

Faixas de IPs privados (decorar!):

10.0.0.0 - 10.255.255.255
172.16.0.0 - 172.31.255.255
192.168.0.0 - 192.168.255.255 ← Mais comum!

Como se conectam? Através de NAT (Network Address Translation) no roteador, que "traduz" IPs privados pra públicos.

Por que meu IP não está funcionando? +

Checklist de problemas comuns:

1. IP duplicado

❌ Dois dispositivos com o mesmo IP
✓ Use DHCP ou verifique IPs manualmente

2. Máscara errada

❌ Dispositivo: 192.168.1.10/24, mas rede é /26
✓ Todos devem ter a mesma máscara

3. Gateway incorreto

❌ Gateway apontando pra IP inexistente
✓ Verifique o IP do roteador

4. IP fora da faixa

❌ Rede: 192.168.1.0/26 mas IP: 192.168.1.100
✓ IP precisa estar entre .1 e .62 nesse caso

5. Firewall bloqueando

❌ Regras muito restritivas
✓ Revise configurações de segurança

Comandos úteis (Windows):

ipconfig → Ver seu IP atual
ping 8.8.8.8 → Testar conectividade
ping 192.168.1.1 → Testar gateway

O que é VLSM e quando usar? +

VLSM = Variable Length Subnet Mask

Conceito: Usar sub-redes de tamanhos DIFERENTES dentro da mesma rede principal.

Sem VLSM (desperdício):

Rede: 192.168.1.0/24

  • Departamento A (100 PCs): /24 → 254 IPs (desperdício de 154)
  • Departamento B (20 PCs): /24 → 254 IPs (desperdício de 234)

Com VLSM (eficiente):

Rede: 192.168.1.0/24

  • Departamento A: /25 → 126 IPs (OK para 100 PCs)
  • Departamento B: /27 → 30 IPs (OK para 20 PCs)
  • Sobra espaço para mais departamentos!

Quando usar:

  • Setores com necessidades muito diferentes
  • Quer aproveitar IPs ao máximo
  • Redes empresariais com vários departamentos
